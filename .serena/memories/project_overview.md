# GameGen Next.js Project Overview

## Purpose
This is a user-generated content platform for pixel art game creation with AI integration. It's built on Next.js 14 with HeroUI v2 components, featuring:
- AI-powered pixel art and asset generation 
- Real-time collaboration features via Supabase
- LLM integration and RAG systems
- User-generated content management

## Tech Stack
- Frontend: Next.js 14 (app directory), React 18, TypeScript
- UI: HeroUI v2, Tailwind CSS, Framer Motion
- Backend: Supabase (PostgreSQL, Auth, Realtime, Storage)
- AI: Anthropic SDK, various AI providers
- Testing: Jest, Playwright, Testing Library
- Desktop: Tauri (optional)

## Key Dependencies
- @heroui/* components for UI
- @supabase/* for backend services
- @anthropic-ai/sdk for AI integration
- Various React libraries (react-window, react-markdown, etc.)
